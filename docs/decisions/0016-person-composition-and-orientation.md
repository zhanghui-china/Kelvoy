# ADR-0016 人物镜头的构图与朝向：脚本规则 + 关键帧命名参考图

状态：已采纳（2026-10-12）

## 背景

用户反馈：首帧里的人物和后面的大佛没有关系，主人公总是面对镜头，应该背对或侧面。查证（GX10 线上数据与
对照实验）：

1. 脚本提示词没有任何构图、朝向、人物与地标位置关系的要求；灵山大佛两期全部镜头都是"空镜无人"。
2. 关键帧把 `kf_prompt` 原样交给 Qwen-Image，并且不说明两张参考图各是什么。多参考图编辑会继承参考图的
   姿态与景别：参考图是正脸自拍时，12/12 都是前景大半身自拍、地标缩成背景。
3. 空镜仍把角色参考图一起传入，提示词却写"无人物"，3 张里有 1 张多出一个自拍的人。
4. H3 改写层按设计"保留源文本的动作与构图、不编造"，所以源文本没写的朝向和位置它不会补。
5. KSampler `cfg=1`，负向提示词无效，只能靠正向描述。

## 决定

1. **脚本层**（`stepfun-llm.ts` 的 `PERSON_SHOT_RULES`）：人物镜头约占一半到七成；有人物的镜头在 `kf_prompt`
   里写明位置、朝向、视线、与地标的关系，wide/medium 写"人物全身入镜、约占画面高度三分之一"；朝向由
   这一镜的剧情动作决定（仰望/走向 → 背影或侧后，互动 → 侧面，打招呼/回眸 → 才可正面）；点名地标用中文名，
   不得出现 id 和 `wide/medium` 等字段取值。朝向写在 `kf_prompt` 文本里，**不新增 Shot 字段**——
   用户已有"修改画面描述"逐镜调整，三层都消费这段文本。
2. **关键帧层**（`stages/keyframe-prompt.ts`）：生成时在 `kf_prompt` 前加图片角色说明
   （"图1是出镜人物的参考图，图2是「地标」的实景参考图。把图1的人物放进图2的实景中…"）。
   记录到 `model.image.prompt` 的是实际发送的完整提示词。
3. **空镜**（`person_visible === false`）且有地标图时不传角色参考图，提示词为"图1是「地标」…画面中没有人物"。
   `keyframeReferences` 新增 `person_omitted`。空镜没有地标图时保持原行为（工作流至少要一张参考图），
   这是已知局限。
4. **视频层**（`h3-prompt-writer.ts`）：约束里加"保持源文本的朝向与视线，不得自行转向镜头""点名的地标是
   00:00 起可见的锚点"；`WRITER_VERSION` 升到 `h3-writer-v2`，让 v1 缓存失效。v2 上线后 GX10 实测改写被 `preserve shot size and camera` 拒绝 7/8（v1 为 2/54）：新句子挤掉了景别与运镜词。v3 在同一处显式要求写出景别与运镜词，并把朝向与地标句缩短。

## 依据（`spike/orientation/`，GX10，2 角色 × 3 地标，同一种子）

| 写法 | 结果 |
|---|---|
| 现状（无构图/朝向） | 12/12 前景自拍正脸 |
| 命名图1/图2 + "面向镜头"（对照） | 12/12 自拍正脸 |
| 只写朝向和位置（不命名） | 12/12 背对或背侧，人物仍占大半画面 |
| 命名 + 背对 / 侧面 | 12/12 背侧 3/4 仰望地标 / 3/4 侧面望向地标，人物可辨认 |
| 命名 + 背对/侧面 + "全身入镜、约占三分之一"（第二轮） | 12/12 全身、约 1/3 画面、地标为主体、没有看镜头 |
| 穿搭图（全身站姿）+ 命名 + 背对 | 6/6 全身背影，衣服一致 |
| 空镜：带人物图 / 不带 | 1/3 多出自拍的人 / 0/3 |

脚本层真实 StepFun 回放（灵山、南长街、泰山各 2 次）：有人物镜头从 0–1/7 变为 6–8 镜里 6–8 镜，几乎不写面向镜头；
第一版规则出现 id 泄漏，加"用中文名称、不要写 id 与字段取值"后 22 条中 0 条。

## 已知局限

- 只有半身参考图时，全身镜头的下半身是模型编的，同一期内不一致（阿澄三镜裤子分别是格子裤、米色裤、牛仔裤）。
  提示词解决不了：要用全身参考图或全身穿搭图。手册与角色编辑页已提示。
- 视频层（H3）没有做实测，只改了约束；上线后用真实一期验证首帧与朝向是否传到成片。
- "人物镜头约占一半到七成"是行为变化：原来全空镜的期会变成主人公出镜；积分估算不变（镜数没变）。
- 参考图视角标签（正/侧/背）与按朝向自动选图没有做；只在上述方式压不住时再立项。
- 脚本 LLM 对更长提示词的遵守度只做了 6 次回放，不是统计结论。
