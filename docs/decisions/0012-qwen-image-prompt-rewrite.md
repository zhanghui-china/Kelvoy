# ADR-0012：本机官方 Qwen 图片提示词增强

状态：已采纳（2026-10-10）；生产启用以模型兼容性与验收通过为前提。

## 职责与契约

当前关键帧流程均有角色参考图，使用 `Qwen/Qwen-Image-2.1-PE-I2I` 的官方 `edit` 模式，不新增纯文字生图入口。Engine 在每镜候选循环前构造画面原稿、动作、景别、机位、场景、参考角色与画幅的纯数据上下文，调用注入的 `imagePromptWriter`。同镜所有候选共享最终 prompt；编辑框 `kf_prompt` 保持中文原稿，字幕不作为画面文字要求。

Worker 负责输入／输出审核、有序文件散列、取消与期内独立缓存。Inference 新增内部 `/image/rewrite/`，使用固定官方代码中的图片预处理、消息构造及答案解析，调用独立的本机增强服务。既有 `/image/` 接收最终 prompt，不进行二次改写。参考图实际进入视觉模型，`<image1>` 为角色；有地标图时 `<image2>` 为场景，顺序与生图上传一致。

沿用 I2I 配套系统提示词与官方采样配置，thinking 开启，仅解析后的答案进入业务记录，思考内容不保存。结果必须为非空英文提示词，参考标记不得越界，`wh_ratio` 必须等于作品的 `9:16` 或 `16:9`，`ratio_follow` 必须为空。格式或画幅冲突最多纠正一次，整次操作上限 900 秒。启用后缺少服务、审核失败、超时、取消或租约丢失均失败，不回退提交原稿。

## 缓存与复现

缓存键包含上下文、有序参考内容散列、画幅、官方代码／系统提示词／模型 revision、编写器版本与采样配置，不含候选编号和租约。有效结果原子发布；重试复用，编辑、换图或版本更新失效。命中仍执行审核和格式验证。图片素材缓存继续包含实际最终 prompt，提交 ComfyUI 前再次核对参考文件散列。

`model.image.prompt` 保存实际提交全文，可选 `qwen_prompt` 保存输入散列、官方与模型版本、编写器版本、模式、画幅及有序参考散列。旧记录无来源字段仍有效，无数据库迁移。改写费用包含在现有图片积分价格中，候选数量、比例、积分预留、退款和手工保存逻辑不变。

## 安装、启用与回退

这是模型服务集成，不安装为 Codex skill。发布携带固定上游提交、模型 revision、来源、许可和 SHA256，运行时不下载代码或权重。独立环境与权重位于 GX10 `/home1/huntun`，安装前检查容量及端口。增强服务仅监听 `127.0.0.1:8110`，并发 1、明确内存预算，不修改共享 ComfyUI、驱动或其他项目环境。

优先官方 vLLM，GB10／aarch64 不兼容时使用官方 Transformers 路径。两条路径都不可用时保留原部署且不启用新链路。通过兼容性、真实少量改写和模拟生图验收后，再按既有备份、空闲队列切换与回退流程启用。保留原黄山作品和固定 7 人运维白名单，不批量重生成历史素材。

验收只允许少量真实提示词改写；图片生成使用模拟模型，临时业务数据验收后清理。验证记录不得宣称真实出图质量已经通过。
