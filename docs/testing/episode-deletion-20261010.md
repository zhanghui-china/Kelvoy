# 作品永久删除验收（2026-10-10）

## 实现范围

作品列表和详情页均提供单个永久删除入口，确认框显示作品名和不可恢复、分享失效、停止任务、退回未结算预留积分的说明。请求期间禁止重复提交，失败可重试。详情的 404 状态显示返回作品列表入口，完成作品在重新聚焦标签页时也会校验存在性。

`DELETE /api/episodes/:id` 在 store 的同一 SQLite 写事务中保存内部删除记录与消费摘要、释放全部作品预留积分、取消活动任务、失效租约并删除作品。重复请求不重复退款。消费流水和历史统计保留；角色、目的地和公共素材不删除。具体协议见 [接口说明](../api/episode-deletion.md)。

Worker 每秒检查取消、正常每 30 秒续租，等待执行退出后确认。媒体与 H3 提示词发布均检查删除状态；迟到写入使持久化清理版本递增，避免文件删除与数据库标记完成之间的竞态。启动及每分钟处理明确标记删除的目录，失败安全记录并退避重试，不扫描旧孤立目录，不跟随符号链接。

## 浏览器与真实文件

使用本地独立账号与三期测试作品核对列表删除按钮、作品名和确认文案、取消默认焦点。删除通过 HTTP 完成后，真实作品目录清理成功，另一作品目录及文件保留。浏览器打开原详情地址，显示“作品已删除或不存在。”与“返回作品列表”；点击返回后列表仅剩未删除作品。

浏览器未点击永久删除确认按钮；请求防重、错误重试和成功回调由组件／控制器测试覆盖，实际删除与文件清理由 HTTP 集成验收覆盖。未使用真实用户作品验收。
