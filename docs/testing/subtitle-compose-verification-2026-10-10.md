# 每镜字幕合成修复验收（2026-10-10）

## 修复范围

- 旧版节拍剪辑将 `Shot.caption` 传入合成计划，保持镜序、选段起点与实际节拍时长。
- 合成与界面共享 `subtitlesEnabled` 判断：字段缺失默认开启，显式 false 关闭。空字幕、纯空白不绘制，不从动作描述自动补齐。
- 所有剪辑方式显示字幕开关、已填写镜数与空字幕提示，转场仅用于固定剪辑。
- 完成页支持保存字幕开关，未保存时禁止重新合成；保存与提交合成是两个操作。
- 已有成片的字幕开关有效变化标记 `final_needs_recompose`。合成失败保留旧成片与重试入口，成功提交新版本后清除标记。
- 原片头、片尾路径可原样保存，新增路径继续限制为已允许的素材；字幕设置保存不覆盖旧配乐。
- drawtext 单引号补齐滤镜参数层转义，避免字幕吞掉后续样式参数。

像素检查位于 `apps/worker/src/compose/ffmpeg.test.ts`，组合为固定／节拍剪辑 × 540×960／960×540 × 有／无片头片尾。使用临时目录的人工色块视频，分别输出字幕开／关两份 MP4，解码字幕区域 RGB 像素：有字幕的抽样帧出现高亮文字，关闭对照为零；镜头边界后、空白镜头以及片头片尾没有字幕。选段起点非零、顺序不按镜号，字幕含中文、换行、单引号、冒号、逗号、大括号与反斜杠。另有合成计划与事件时间测试核对镜序、固定帧窗、不同节拍时长、片头偏移和空白内容。

Linux 检查在一次性 Ubuntu 24.04 容器中使用官方软件源 FFmpeg 与 Noto CJK 字体，仅挂载 `/private/tmp`。宿主测试调用容器的 ffmpeg/ffprobe，ASS 为实际自动选择路径；drawtext 检查仅在测试包装器的能力列表中隐藏 ASS，并设置临时字体文件。生产代码未增加渲染模式或环境开关。两个路径各运行：

```sh
bun test apps/worker/src/compose/ffmpeg.test.ts -t 'caption pixels'
```

接口／任务集成测试还核对：默认缺省到显式 true 不标记成片失效，切换 false 后标记；保留素材、镜头与原成片；保存不入队；重新合成失败并重试后才更新成片版本，全程没有图片／视频任务。

完整测试最初受沙箱限制无法监听 HTTP 测试端口，允许本机监听后全量通过。Python 留有现有 Starlette/httpx 弃用警告，不影响结果。

## 浏览器验收

通过原生 Chrome 访问本机隔离服务，使用 `/private/tmp/kelvoy-subtitles-browser/test.db` 与两个独立测试作品，未使用业务数据库：

- 完成页缺省开关为开启，显示 1 / 2 镜；关闭后明确提示本次不显示字幕。
- 修改开关后保存按钮可用、重新合成禁用；保存成功后重新合成恢复，页面标记当前为上一版成片。
- 字幕编辑显示“保存后需合成／重新合成才会更新成片”，按钮为“保存字幕”；保存新字幕回到脚本审核，原视频片段保留。
- 旧版合成设置显示字幕开关，不显示转场。修改开关后开始合成禁用，保存后恢复。
- 原有片头／片尾／配乐路径正确展示，字幕设置保存后原样保留；整页刷新确认开关持久化。

独立代码审查未发现需要修复的问题。静态前端测试的交互覆盖不足由上述浏览器验收补充。
