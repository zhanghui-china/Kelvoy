## 实现约束

- 回看组件不接收 mutation 对象，只导入读取素材 URL 与本地 CSV 导出能力。
- 原操作区保持挂载以保留本地输入；隐藏时暂停视频，并拦截隐藏视频的延迟播放事件。
- 已保存素材是曾到达阶段的证据，允许重新编辑的作品查看保留的素材；未知失败逐阶段按数据判定，不推断尚未保存的阶段。
- 展示当前保存内容，没有历史版本恢复；缺失快照、空素材与文件加载失败均明确显示，不自动生成或修复。
