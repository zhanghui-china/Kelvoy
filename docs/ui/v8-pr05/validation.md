# PR05 资源库验收

目的地和模板支持关键词与类型组合筛选，空结果可清除筛选。角色按“我的／官方”来源切换。资源卡片的“使用”入口预选对应目的地、模板或角色；新建页只接受当前账号目录中真实存在的 ID，已填写的其他草稿字段保持不变。目的地的国家、省份与简介为可选内容，旧数据缺失时不显示空字段。模板没有真实封面字段，因此卡片使用明确标注为“叙事类型示意”的 CSS 图块。

测试：`make typecheck` 五个 workspace 通过；`make test` 642 个 Bun、44 个 Python 测试通过；Web 生产构建通过；`git diff --check` 通过。浏览器使用本地隔离 API 夹具验证目的地筛选交集与清空、官方角色只读、三个“使用”入口、模板选中后刷新与草稿保留、无效 ID 忽略、390px 无横向溢出。浏览器脚本最初用精确标签查找创作要求字段时未匹配；改为读取对应 textarea 后，同一数据保留断言通过。夹具中的角色图片缺失和积分数仅用于测试，不代表生产数据。
