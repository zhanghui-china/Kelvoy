# PR11 成片与用量验收

## 已实现

- 成片页按成片元数据设置播放器画幅，横版和竖版均保持原始比例；移动视口将播放器与交付操作排成单列。旧作品缺少 `final` 元数据时仍沿用既有成片路径，不把历史文件误判为不存在。
- 成片信息、MP4 下载入口与分享操作集中展示，原有的分享开关、二维码、文案复制及权限路由继续复用。
- 用量页没有作品时仍显示真实的已用积分、API 费用和总期数（0 值）；按期区域提示“还没有创作记录”。余额和流水继续由独立积分接口提供。

## 验证

- `bun run typecheck`：通过。
- `bun test apps/web/src/frontend/review/DoneView.test.tsx`：1 项通过，涵盖横版元数据画幅及旧作品下载兼容。
- `bun test`：672 项通过。
- `bun run --cwd apps/web build`：通过。

## 数据边界

- 当前按期与总计的 API 费用来自镜头模型记录 `cost_usd`；积分来自现有 `credits_used` 与实际账户流水。本 PR 没有把积分估算或镜头耗时当成实测 GPU 分钟。
- `ShotModelRecord` 尚无可信的 GPU 运行时长，不能按现有 API 汇总真实 GPU 分钟。需在任务执行层记录、持久化并经实测校准后新增字段。
- 分镜表 PDF 尚无服务端持久产物或生成器。本 PR 不在界面放置无效的下载按钮；PDF 应作为后续交付功能独立实现和验收。

## 隔离浏览器验收

本机 Vite 仅监听 `127.0.0.1:5179`；Playwright 拦截 `/api`，提供固定成片与用量夹具。截图只验证前端呈现，不代表真实视频播放、下载端点或生产权限验收。

- 390px、1440px 的成片与用量页面均无 JavaScript 异常；四次测量的页面 `scrollWidth` 与视口宽度一致，无整页横向溢出。
