# PR04 公开页缺口验收

## 审计结论

现有 v9 官网已覆盖独立布局、真实目的地数据、登录入口、响应式区块、AI 表述和减少动画偏好。已有证据见 `docs/superpowers/plans/2026-09-27-landing-v9.md`，内容与路由回归见 `ManagementGuidance.test.tsx`。本次未改动任何 `Landing*` 文件，不回退 v9。

只补齐以下缺口：

- 分享请求期间显示可访问的加载状态，避免空白页面。
- 失效分享使用自己的居中容器，避免受到登录页双栏 `.k-auth-shell` 规则影响；保留原有失效文案与接口行为。
- 分享标题允许长连续文本换行；正常分享保留视频比例、AI 标识、尺寸、时长和下载入口。
- 登录表单在桌面右侧栏居中；补齐用户名/密码自动填充、提交忙碌及错误提示语义。

- 1440 / 1280 / 768 / 390px：登录与分享内容无横向溢出。
- 1440px 登录表单在右侧栏居中；390px 保留单栏输入与完整提交按钮。
- 分享加载时存在 `role=status` 文案；失效链接居中显示，不再出现登录页空白双栏。
- 390px 连续英文长标题换行，视频和下载入口保持可见可达。
- 提交测试登录失败后显示 `role=alert` 错误，提交按钮恢复可用。
- 浏览器控制台未发现错误；验收后恢复浏览器视口并关闭测试标签。
