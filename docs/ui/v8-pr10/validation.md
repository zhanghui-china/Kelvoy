# PR10 关键帧与片段审核验收

- 关键帧与片段审核默认聚焦第一镜；上一镜、下一镜、待审队列均可切换，URL 的 `shot` 参数仍可恢复当前镜；“查看全部镜头”可展开原有列表。
- 片段审核中，如果截取起点有未保存修改，“通过这一镜”先保存起点；保存失败则不提交通过。
- 使用 24 镜本地隔离 fixture 在 Chromium 检查 390px 与 1440px：键盘右箭头、上一镜/下一镜、单镜/全部切换均成功，文档宽度等于视口宽度，无 JavaScript 异常。截图：[关键帧手机](keyframes-390.png)、[关键帧桌面](keyframes-1440.png)、[片段手机](clips-390.png)、[片段桌面](clips-1440.png)。
- Fixture 使用占位 SVG 关键帧和不可播放的片段路径，仅验证界面与导航；未验证真实视频播放、GPU 生成、服务端写入或付费重生成。现有权限与直接视频流程未改动。
