# PR10 关键帧与片段审核验收

- 关键帧与片段审核默认聚焦第一镜；上一镜、下一镜、待审队列均可切换，URL 的 `shot` 参数仍可恢复当前镜；“查看全部镜头”可展开原有列表。非当前镜保持挂载，切换后未保存的提示词、截取起点和本地质量确认仍在。
- 片段审核中，如果截取起点有未保存修改，“通过这一镜”先保存起点；滑块失焦与通过点击共享同一次保存请求，保存失败则不提交通过。
- `scripts/verify-pr10-review.py` 的浏览器交互回归检查：提示词和选段/勾选状态跨镜保留，切镜后滚动定位；滑块聚焦且起点已修改时，单次点击通过只发一次起点 PATCH（版本 1）再发一次通过 PATCH（版本 2）；连续触发两次点击仍只发这两次写入；起点保存失败时不发通过请求。
- 使用 24 镜本地隔离 fixture 在 Chromium 检查 390px 与 1440px：键盘右箭头、上一镜/下一镜、单镜/全部切换均成功，文档宽度等于视口宽度，无 JavaScript 异常。截图：[关键帧手机](keyframes-390.png)、[关键帧桌面](keyframes-1440.png)、[片段手机](clips-390.png)、[片段桌面](clips-1440.png)。
- Fixture 使用占位 SVG 关键帧和不可播放的片段路径，仅验证界面与导航；未验证真实视频播放、GPU 生成、服务端写入或付费重生成。现有权限与直接视频流程未改动。
