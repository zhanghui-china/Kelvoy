# PR09 脚本审核与阶段导航验收

基线为已合并 PR08 恢复部分的 `origin/main` (`0191220`)。HTML v8 只作视觉参考；镜头数、镜头分类和下一步路径均来自真实期数据与状态，不使用原型演示值。

## 已核对行为

- 阶段导航按 `video_source` 显示直出五步或传统关键帧六步。当前、已完成、失败、未知失败和待开始有明确状态；完成作品不保留 `aria-current`。直出素材准备失败与视频片段失败分别说明，步骤不是可跳转按钮。
- 脚本表格/故事板与脚本助手在桌面双栏、窄屏单栏。原有编辑、重排、删除下限、优化/重新生成、处理中与错误提示、继续到正确生成路径均保留。
- “导出脚本 CSV”由当前 `episode.shots` 顺序生成，包含真实场景和地标名称；UTF-8 BOM、CRLF、CSV 引号/换行转义和公式前缀防护已做单元测试。导出不调用写入 API。

## 隔离浏览器验收

本机 Vite 仅监听 `127.0.0.1:5177`；Playwright 拦截 `/api/me` 与单个作品详情，提供 24 镜固定夹具。它只验证前端布局与下载交互，不代表真实生成或服务器权限验收。

| 视口 | 页面 scrollWidth / innerWidth | 脚本布局 | 表格 scrollWidth / clientWidth |
| --- | --- | --- | --- |
| 390px | 390 / 390 | 单栏 | 960 / 358，表格内部可横滚 |
| 768px | 768 / 768 | 单栏 | 960 / 480，表格内部可横滚 |
| 1440px | 1440 / 1440 | 脚本 812px + 助手 320px | 960 / 812，表格内部可横滚 |

三个视口均无页面 JavaScript 异常；390px 切换故事板后页面仍为 390px 宽。浏览器实际下载 CSV 文件，含 UTF-8 BOM、标题行和 24 镜数据（25 行）。截图：[脚本 390px](script-390.png)、[脚本 768px](script-768.png)、[脚本 1440px](script-1440.png)、[故事板 390px](storyboard-390.png)。
