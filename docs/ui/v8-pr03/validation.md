- 390px：菜单开启锁定背景滚动；关闭按钮、Escape、遮罩点击和选择导航均关闭菜单，返回菜单触发按钮焦点并恢复滚动。
- 抽屉开启时调整到桌面宽度：关闭模态并恢复背景滚动。
- 原生 dialog 在嵌入式浏览器中 Shift+Tab 可将焦点移到浏览器外层，因此增加显式首尾循环；复验 Shift+Tab 从关闭按钮到退出登录、Tab 从退出登录到关闭按钮均通过。
- 设置页 390px 无横向溢出；浏览器控制台无错误。
