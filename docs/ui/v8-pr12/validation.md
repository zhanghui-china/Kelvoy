# PR12 设置与帮助验收

保留现有真实积分、默认候选数、密码修改、新手引导和六阶段审核指南。帮助页增加可搜索的完整目录，结果链接原有稳定锚点，正文始终可读；搜索覆盖流程、资源和常见问题。设置页在宽屏采用双栏、窄屏单栏，加载失败可重试，保存成功有状态反馈；不添加虚构的客服、发票或成员管理功能。

验证：`make typecheck` 五个 workspace 通过；`make test` 641 个 Bun、44 个 Python 测试通过；Web 生产构建 218 模块通过。浏览器使用隔离内存 API，在 1440px 与 390px 验证搜索“横屏”到 FAQ 原锚点、全目录、设置布局无横向溢出、保存状态，以及模拟持续 API 失败后的手动重试。浏览器无页面异常。测试账号和余额均为夹具，不是实际用户数据。

独立审查发现“CSV/PDF 导出”写在帮助正文却不在搜索索引，另有设置保存后再编辑仍显示“已保存”。现补齐对应搜索词和测试，保存请求期间锁定字段，编辑后清除旧成功提示。一次性夹具复测 `CSV` 返回“失败、重试与积分”原锚点；390px 帮助页无横向溢出，设置保存后改动语气即清除成功提示。
