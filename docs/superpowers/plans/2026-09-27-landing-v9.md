# Kelvoy v9 官网落地页实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将用户提供的 v9 HTML 视觉体系应用到 Kelvoy 现有独立落地页，并保持入口、目的地数据和产品能力真实可用。

**Architecture:** 继续使用 `LandingPage` 组合现有 React 分区组件，官网样式限定在 `.k-lp-page` 下，不改工作台全局样式。Hero 图从用户提供的 HTML 提取为独立静态资源；目的地照片仍从 `/api/destinations` 对应的真实素材接口加载。无需改动业务数据模型与生成服务。

**Tech Stack:** React、TypeScript、Vite、Hono 公共目的地接口、CSS。

---

## 视觉与内容准则

- 版心最大 1200px；白色背景、`#2563EB` 蓝色强调、`#111827` 主文字、淡蓝辅助面板、柔和阴影和 12–20px 圆角。
- 顶部导航、左右分栏 Hero、三张用户卡、三张优势卡、四步流程、动态目的地网格、FAQ、深蓝底部 CTA 和深色页脚依次排列。
- 保留“可旅，让每一场旅行都有 vlog”主标题。所有按钮必须通往真实页面或锚点。
- 去掉模板中无法验证的免费试用、固定 30 分钟、1/10 成本、自动地标评分、批量产能和自动封面/文案承诺。默认双参考视频流程只需脚本与片段审核；传统关键帧审核是可选路径。
- 页面在 1440、1024、390 宽度无整体横向溢出；键盘焦点清晰，图片有替代文本，减少动画偏好得到尊重。
