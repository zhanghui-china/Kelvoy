# Kelvoy Web 端操作手册

> 版本: v1.0  
> 更新: 2026-09-29  
> 项目: Kelvoy · 可旅 —— AI 旅行 Vlog 生产工作台

---

## 一、系统概述

Kelvoy Web 是旅行 Vlog 生产工作台的可视化操作平台。选定一个虚拟出镜角色和一个景区级目的地，系统自动完成脚本生成、素材准备、视频生成与合成；你在脚本、关键帧（传统路径）、片段三个节点做选择，最终得到一期 24–30 镜、每镜 1 秒、约 30 秒、9:16 竖屏（默认）或 16:9 横屏的旅行 Vlog。同一角色走遍不同目的地，形成系列化的旅行账号内容。

### 1.1 系统特性

- **两条创作路径**：新项目默认"人物 + 场景直出视频"（省去图片生成与关键帧审核）；也可选传统"关键帧候选 → 图生视频"路径精修画面
- **三个人工审核点**：脚本可改可删可重排、关键帧逐镜挑选、片段逐镜确认五项质量红线——生成过程全程可干预
- **失败可重试**：任何生成阶段失败都能从断点重跑，已成功的产物保留不重做
- **成本透明**：提交前实时预估积分；用量页展示余额、流水、按期与按模型的实际费用
- **成片可分享**：版本化成片 + 公开分享链接（含二维码与文案复制），可随时关闭

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│              前端（React 18 + Vite + TypeScript）            │
│  官网 / 登录 / 新建一期 / 审片台 / 资源库 / 用量 / 分享页    │
├─────────────────────────────────────────────────────────────┤
│              服务层（Hono API，端口 3000）                   │
│  账号 · 角色 · 目的地 · 模板 · 期 · 审核写操作 · 分享        │
├─────────────────────────────────────────────────────────────┤
│              数据层（SQLite 唯一真源 + 乐观锁）              │
├─────────────────────────────────────────────────────────────┤
│              生成层（Worker + 本地推理服务 + ffmpeg）        │
│  脚本(StepFun) · 图像(Qwen-Image 2.1) · 视频(MiniMax H3)     │
└─────────────────────────────────────────────────────────────┘
```

## 二、登录与退出

### 2.1 登录页面

打开 Web 地址后，首先进入登录页面：

- **用户名输入框**：输入团队分配的用户名
- **密码输入框**：输入对应密码（密码以密文形式显示）
- **登录按钮**：点击后验证身份，通过后进入工作台首页
- **错误提示**：登录失败时显示红色错误信息

> **注意**：系统不支持自助注册，新账号需联系团队管理员在服务器上用 CLI 创建。

### 2.2 退出系统

登录后，侧栏底部显示当前用户名（含可用 / 预留积分摘要）和"退出登录"按钮：

1. 点击侧栏底部的"退出登录"
2. 系统清除会话与未提交的建期草稿，返回登录页面

## 四、新建一期

### 4.1 表单字段说明

页面分左右两栏：左侧"本期内容"表单，右侧"选择出镜角色"。

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 本期名称 | 文本输入 | 否 | 目的地建议名 | 用于工作台识别；成片标题在合成设置中单独填写 |
| 目的地 | 下拉选择 | 是 | 第一个目的地 | 显示"城市 · 景区名（类型）"；选定后显示场景参考示例图 |
| 季节 / 时段 | 快捷选择 | 否 | 目的地推荐季 | 可点"自定义"输入（如"早春"）；跟随目的地切换 |
| 画幅比例 | 快捷选择 | 是 | 9:16 竖屏 | 可选 9:16 / 16:9，影响生成与成片 |
| 风格 / 语气 | 文本输入 | 否 | 账号默认语气 | 快捷 chip：松弛 / 治愈 / 活力 / 文艺，点一下填入 |
| 创作要求 | 多行文本 | 否 | — | 写想呈现的重点、情节、地标或画面偏好 |
| 视频生成方式（高级） | 下拉选择 | 是 | 人物＋场景直出视频（推荐） | 直出跳过图片与关键帧审核；传统方式可选关键帧候选 |
| 模板（高级） | 下拉选择 | 是 | 匹配目的地类型 | 决定镜头骨架；显示 LUT / 片头片尾 / 标题样式详情 |
| 穿搭覆盖（高级） | 文本输入 | 否 | 角色默认穿搭 | 本期换装，不改角色资产 |
| 禁止项（高级） | 标签输入 | 否 | 可读文字、真人 | 按逗号 / 顿号 / 回车分隔添加，点 × 删除 |
| 每镜候选数（高级，仅传统方式） | 下拉选择 | 是 | 3 | 可选 1–3 张；影响预估积分 |

右侧角色面板分"我的角色 / 官方角色"两个标签，点卡片选中；没有合适角色时可点"＋ 新建角色"（保存后返回继续）。

### 4.2 快捷入口与草稿

- 首页"发现目的地"卡片、目的地库"用这个目的地新建一期"会带 `?destination=` 参数直达并预选，同时自动匹配模板与推荐季节；
- 角色 / 模板页也提供带参跳转（`?persona=` / `?template=`）；
- 未提交的表单内容**自动存草稿**（当前浏览器会话内，按账号隔离）：切到别的页面再回来不丢；提交成功或退出登录后清除。

### 4.3 提交生成

提交前表单底部实时显示 **"预计完整创作 N 积分 · 约 M GPU 分钟"**（随创作方式与候选数变化）：

1. 确认角色、目的地、画幅与创作方式；
2. 点击"创建这一期"；
3. 创建成功后跳转到作品详情页（审片台），进入脚本生成阶段。

若创作要求或禁止项命中内容拦截，提交会被拒绝并逐条列出违规项，修改后重试。

## 五、审片台总览

打开作品详情页即进入审片台。顶部显示期名、状态徽章、期号、角色、目的地、预估积分与镜数；其下是**阶段进度条**：

- 直出方式 5 步：创建项目 → 分镜脚本 → 视频片段 → 合成预览 → 成片分享；
- 传统方式 6 步：创建项目 → 分镜脚本 → 关键帧 → 视频片段 → 合成预览 → 成片分享；
- 当前阶段高亮，已完成打勾，失败阶段标红并提示失败环节。

生成过程中页面**每 3 秒自动刷新**，无需手动操作。页面底部提供"把本期设置存为私有模板"入口。

---

## 六、审核 1：脚本

脚本生成完毕进入"待审脚本"，提供两种视图：

- **表格视图**：逐镜列出镜号、场景、时段、景别、动作 beat、字幕、机位、地标、关键帧 prompt（表格可横向滚动）；
- **故事板视图**：逐镜卡片，适合通读叙事。

### 6.1 编辑镜头

点击"编辑"展开镜头编辑器，可修改：场景时段、景别（远景 / 中景 / 近景 / 特写 / 主观视角）、动作 beat、字幕、机位（固定 / 横摇 / 推进 / 跟随）、地标引用、关键帧 prompt 与运动 prompt。

### 6.2 删镜与重排

- **删除**：逐镜删除，**下限 24 镜**，不可新增镜；删后系统自动重校验镜头结构规则（同景别不连续 > 2、地标镜头 ≥ 5 等）；
- **重排**：表格内上移 / 下移调整镜头顺序，镜号自动保持连续。

### 6.3 导出 CSV

点击"导出 CSV"下载当前脚本表格（带 BOM，Excel 直接打开不乱码；自动防护公式注入）。

### 6.4 脚本助手

右侧"脚本助手"面板：

- **优化指令**：输入 ≤500 字的调整要求（如"增加夜景镜头，让美食段落更有生活感"），点"按指令优化"——在现有脚本基础上改写；
- **重新生成**：整份脚本推倒重来；
- 优化 / 重新生成可能消耗积分；处理失败会保留当前脚本并提示重试。

确认后点击底部"继续"：直出方式为"继续 → 用人物与场景生成视频"，传统方式为"继续 → 生成素材与关键帧"。

---

## 七、审核 2：关键帧（传统路径）

每镜生成 1–3 张候选关键帧，**候选按生成顺序并排显示，不排序、不打分**——质量判断交给人工：

- **选定**：点击一张候选即选中（再点可换）；已选 / 当前镜高亮；
- **对照参考**：右侧并排显示该镜地标的实景参考图与角色参考图，帮助核对地标形态与人物一致性；
- **重生成**：效果不满意可"直接重生成"，或展开"改 prompt 并重生成"（先保存新 prompt 再重生成）；
- **策划稿**：可展开查看网格策划稿（只看不审，不是审核点）；
- **导航**：顶部"上一镜 / 下一镜"逐镜切换，或展开全部镜头；右侧待审队列显示剩余待决策镜数，点击直达。

全部镜头选定后，"继续 → 生成视频"按钮可用。

---

## 八、审核 3：片段

每镜生成 3–5 秒视频片段，从中截取严格 1 秒进入成片：

- **选起点**：拖动滑块调整截取起点（按 30fps 帧格吸附），拖动时**实时预览那一秒**；起点会自动保存；
- **五项质量红线**：人物一致、手部正常、地标形态正确、物理合理、无可读文字——**全部勾选后"通过这一镜"才可用**（勾选状态仅本次审核有效，不入数据模型）；
- **标记重生成**：片段不合格时标记，Worker 重跑该镜视频；
- **报告坏镜**：每镜**免费重生成一次**，报即生效（按钮变"已报告"）；
- **旧版作品**：沿用原节拍选段；可点"使用新版 1 秒剪辑"转换（保留片段，逐镜重新确认）。

全部镜头通过后进入下一步："合成设置"。

---

## 九、合成设置与成片

### 9.1 合成设置（compose_ready）

片段全部通过后，先确认合成参数（**修改任何选项后必须先点"保存设置"，"开始合成"才可用**）：

| 设置 | 说明 |
|---|---|
| 成片标题 | ≤80 字，显示在成片上 |
| 烧录每镜字幕 | 新版默认开启；按每镜一秒窗口烧录 |
| 切点前后各 2 帧淡出淡入 | 新版默认开启；片内转场，总帧数不变 |
| 配乐 | 按创作语气自动选曲，或从授权曲库指定（显示 BPM） |
| Kelvoy 片头 / 片尾 | 默认关闭；片头 1.2 秒、片尾 1 秒 |

页面同步显示预估时长（镜数 × 1 秒 + 片头片尾）、分辨率与帧率。点击"开始合成"后由 Worker 执行 ffmpeg 合成，页面每 3 秒刷新进度。

### 9.2 成片交付（done）

合成完成进入成片页：

- **播放校验**：先完整播放检查画面、字幕与声音；显示时长、分辨率、帧率、文件大小与完成时间（ffprobe 校验后的交付元数据）；
- **下载**：下载 MP4 成片；
- **重新合成**：只重跑合成，不动任何已通过的镜头；
- **重做镜头**：逐镜重生成关键帧（传统方式）或视频，审核新结果后再合成；
- **旧作品转换**：旧逐镜项目可"使用新版 1 秒剪辑"（转换后旧成片暂停交付，新成片完成并恢复分享）；
- **成本报告**：显示预估 / 实际积分与按 provider / model 的镜次、尝试次数、成本（USD）汇总；
- **存为模板**：把本期的骨架 / LUT / 片头片尾 / 标题样式存为私有模板。

## 十、分享功能

### 10.1 开启 / 关闭分享

在成片页"分享"卡片：

1. 点击"开启分享"，生成公开链接（`https://<站点>/s/<slug>`）；
2. 关闭分享后链接立即失效；**重新开启拿回同一个 slug**，发出的旧链接恢复可用；
3. 分享页不需要登录，只含成片与分镜信息，不含账号信息；链接不随 90 天清理失效。

### 10.2 分享动作

- **复制文案**：标题 + 前三条字幕 + "AI 生成 · 虚构角色 · 真实目的地" + 链接，一键复制；
- **复制链接**：仅复制分享 URL；
- **平台入口**：打开抖音创作者中心 / 小红书（仅打开网站，发布需自行完成，系统不做自动发布）；
- **二维码**：微信扫码直接打开分享页，方便转发。

## 十一、资源库管理

### 11.1 角色

角色卡显示参考图（前三张）、版本号、官方 / 私有、锁定特征、默认穿搭与账号风格（LUT / 标题样式）。参考图不足 3 张会提示"参考图不足"。

**新建 / 编辑角色**表单：

| 字段 | 说明 |
|---|---|
| 名称 | 必填 |
| 描述 | 人物小传（年龄、发型、体态、气质） |
| 锁定特征 | 脸型 / 发型 / 体态等，跨期必须保持一致的部分 |
| 默认穿搭 | 日常着装描述，建期时可覆盖 |
| LUT / 标题样式 | 账号级画面风格，从现有模板选项中选择 |
| 参考图上传 | **3–7 张**，支持点击选择与拖拽；单张 ≤ 10MB；先本地预览，提交时统一上传 |

编辑已有角色会生成新版本，历史版本被旧期继续引用。官方角色对所有人只读。

“我的角色”卡片提供“编辑”和“删除”。删除前会显示角色名称，并提示其不能再用于新建一期；已创建作品、历史角色版本与照片会保留，原账号仍可继续生成和查看。删除成功自动刷新列表，失败可重试；遇到版本冲突应先刷新核对，再重新决定是否删除。编辑和删除不扣积分。本次不提供回收站和恢复入口。

### 11.2 目的地库

目的地库包含官方资源和用户发布的共享资源：

- 顶部支持**关键词搜索与六种类型筛选**（名山登顶 / 城市街区夜游 / 主题小镇 / 大型景区 / 古镇水乡 / 海岛）；
- 每个目的地展示：推荐季节、动线、地方饮食、交通、住宿；
- 每个地标配实景参考图（≥3 张达标）、最佳拍摄时段与"须保真"特征；
- 点"用这个目的地新建一期"直接进入建期页并预选。

点击“创建目的地”填写名称、城市和类型，按地标补齐名称、最佳机位／时段及须保真特征。照片按地标批量上传，支持 JPEG、PNG、WebP，每张最多 10 MiB，每地标最多 10 张。“保存草稿”允许未补齐，在“我的草稿”继续编辑，也可移除照片。草稿与照片仅自己可见。

每地标 3–10 张实景照片且必填信息完整后，点击“发布到共享库”。页面会明确提示照片将对所有用户公开共享，无需管理员审核。发布后可直接“用这个目的地新建一期”。只有创建者可以编辑自己的共享目的地；编辑先生成私有草稿，发布新版本后旧期仍使用创建时的版本及照片。介绍、季节、动线、饮食、交通、住宿可不填。创建、上传、发布不扣积分。

### 11.3 模板中心

- 分"官方模板 / 我的模板"两组；模板 = 骨架 + LUT + 片头 + 片尾 + 标题样式；
- 可新建私有模板（填名称、骨架、LUT、片头片尾、标题样式）、删除自己的模板；
- 成片页也可把当前期设置一键存为模板。

## 十二、我的作品与首页

### 12.1 我的作品

- **筛选**：关键词（期名 / 角色 / 目的地）、状态（草稿 / 进行中 / 已完成 / 失败）、地区（国内 / 海外）、省份、季节；
- **系列视图**：按出镜角色归组显示，同一角色的多期作品集中管理；
- 每行显示状态徽章，点击进入审片台继续或查看。

### 12.2 首页

- **继续上次**：最近一期进行中的作品直达卡；

## 十五、常见问题

### 15.1 "人物＋场景直出视频"和"关键帧"怎么选？

直出（默认推荐）：跳过图片生成与关键帧审核，速度更快、积分更省，适合大多数场景。传统关键帧：每镜先出 1–3 张候选图人工挑选，再图生视频，适合需要精确控制构图的期。旧项目不会自动转换。

### 15.2 提示"version_conflict / 数据已被更新"怎么办？

多个标签页或多人同时操作同一期会触发写冲突。系统会自动用服务端最新数据刷新页面，**重新检查一遍再操作**即可，你的本轮未提交改动需要重做。

### 15.3 为什么不能新增镜头？删镜有什么限制？

审核 1 只支持改、删与重排（脚本结构规则在生成时已保证成片质量），**下限 24 镜**，低于下限无法继续删除。

### 15.4 生成失败了怎么办？

作品页会显示失败阶段与原因，点击"重新执行失败任务"即可从断点重跑；**已成功的产物（候选、片段）会保留并复用**，不会重复消耗积分。

### 15.5 "报告坏镜"和"标记重生成"有什么区别？

两者都会重跑该镜视频；区别是**每镜第一次报告坏镜免费**（不扣积分），之后按正常动作计费。传统路径还可单独重生成关键帧。

### 15.6 为什么"开始合成"按钮是灰的？

合成设置页修改过任何选项（标题、字幕、转场、配乐、片头片尾）后，必须先点"保存设置"，保存成功后"开始合成"才可用。

### 15.7 分享链接关闭后再开启，链接会变吗？

不会。slug 在首次开启时生成并保留，关闭只是暂停访问，重新开启拿回同一个链接。

### 15.8 旧作品怎么改成每镜 1 秒的新剪辑？

在片段审核页或成片页点"使用新版 1 秒剪辑"：保留全部片段，每镜回到待确认状态，重新选起点并通过五项红线后进入合成设置。转换期间旧成片暂停交付，新成片完成后按原分享开关恢复。

### 15.9 新建一期的草稿会丢吗？

草稿保存在当前浏览器会话中（按账号隔离），切页不丢；提交成功、退出登录或换账号后清除。换浏览器 / 设备看不到这份草稿。

### 15.10 角色参考图上传失败？

检查张数（总数 3–7 张）与单张大小（≤10MB）；编辑页不选新文件时不会校验张数，可先保存资料再补传。

### 15.11 预估积分和实际消耗为什么不一样？

预估按"镜数 × 候选数 × 单位成本 × 1.5 返工系数"粗算（建期时镜数未知，用默认 28 镜）；实际按任务成功结算，失败释放、坏镜免费，重生成次数不同会导致差异。

### 15.12 导出的脚本 CSV 打开是乱码？

CSV 带 UTF-8 BOM，Excel 可直接打开；如用其他工具，请选择 UTF-8 编码。

## 十六、安全提示

### 16.1 AI 内容标识

成片带右下角半透明水印"AI 生成 · 虚构角色 · 真实目的地"及文件元数据标识（符合《人工智能生成合成内容标识办法》），分享页也标注 AI 生成身份。这是固定行为，不可关闭。

### 16.2 内容拦截

创作要求与禁止项会做关键词拦截，命中即拒绝提交并列出违规项；默认禁止项为"可读文字、真人"，可按需增删。

### 16.3 数据与版权

- 你的角色与作品仅自己和官方资产可见；分享页不含账号信息；
- 上传真人参考图需自行确认拥有相应权利；
- 音乐只来自授权曲库；地标画面以实景参考图为准，失真属质量红线。
