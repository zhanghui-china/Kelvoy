## 二、提示词设计

### 2.1 两种场景策略

根据参考图数 N 与参考视频人数的关系，采用不同策略：

| 场景 | 策略 | 说明 |
|---|---|---|
| N=1（图 < 视频人数） | **部分替换** | 替换视频中一个人，另一个人保留原样 |
| N=2（图 = 视频人数） | **全量替换** | 替换视频中所有人 |
| N≥3（图 > 视频人数） | **人物扩展** | N 个图人物在视频场景中模仿动作 |

## 五、生产配置建议

| 参数 | 建议值 | 依据 |
|---|---|---|
| `GENERATION_TIMEOUT` | **2400** | 9 图 1310s，留 83% 余量 |
| `megapixels` | 0.9 | 生产推荐最高档 |
| `duration` | 5s | 本轮验证通过 |
| `steps` | 8 | Turbo 默认 |
| N < 视频人数 | 用**部分替换**提示词 | V4 模板（替换指定人，保留其余人） |
| N ≥ 视频人数 | 用**全量替换/扩展**提示词 | V3 模板（严格人物隔离） |

## 六、已知限制

1. 模型输出分辨率 1280×736，低于参考视频原始 1080×1920
2. 模型输出帧率固定 24fps（参考视频为 30fps）
3. 人数一致性依赖提示词约束，N>5 时可能出现帧间漂移
4. 9 图满配单次生成约 22 分钟，批量场景需排队
5. 音频行为可通过提示词控制（"音频保持安静"），但效果需逐案验证
