# 三视图可行性实验（T0）

日期 2026-10-13，GX10，ComfyUI 单参考图（`1_1_SingleRef2IMG`）与双参考图（`1_2_DualRef2IMG`）工作流。脚本 `three_views_experiment.py`，对照图在 `out/`。

## 设置

- 素材：官方角色阿岚（`c_official_alan/full.jpg`）、阿澄（`c_official_aching/full.jpg`），都是 AI 生成的写实全身照，背景杂乱。地标：灵山大佛、南长街、泰山各 1 张。
- 阶段一（views）：1 张全身照 → 正 / 侧 / 背，3 个提示词变体 × 2 角色 × 3 视角 = 18 张，固定种子。
- 阶段二（keyframes）：V1 的三视图横拼成一张设定图（方案 A，2304×1376）作图 1，地标作图 2，走现有双参考工作流；2 角色 × 3 地标 × 2 种子 = 12 张。对照：原全身照 + 地标（现状），每角色每地标 1 张，共 6 张。

## 结果（均为人工目视）

| 项 | 结论 |
| --- | --- |
| V1「设定图」 | 正 / 侧 / 背视角规范，纯白背景，服装与背包一致；3 个变体里最稳 |
| V2「命名中性」 | 视角基本对，但正面、侧面带手插口袋等姿势，不够统一 |
| V3「简短」 | 阿澄背包在侧面、背面视角丢失，阿岚侧面不是真正的 90° 侧面；不合格 |
| 方案 A 关键帧 | 12/12 单人，没有把设定图的拼图画进画面；服装、背包保留；地标清晰可辨 |
| 与现状对照 | 地标与人物一致性相当；人物朝向由提示词决定（本次写的是侧身） |

## 结论

- 质量门槛：**通过**（样本有限，见下）。
- 消费方式：**推荐方案 A**（拼成一张设定图作单一人物参考，`refs.length` 不变）。方案 B 没跑，只确认模板 `1_4_QuadRef2IMG` 已在 `comfyui-bridge/`，接入需要在 `comfyui.py` 增加 4 参考分支并改关键帧提示词与 H3 参考角色；ADR-0015 已证明多张同一人图片有画成多人的风险，不建议优先。

## 推荐提示词（V1，逐字，`{视角}` 取 正面 / 侧面 / 背面）

```
把人物改为全身角色设定图：{视角文本}，纯白背景，人物居中，全身入镜，双臂自然下垂，保持人物的脸型、发型、服装、鞋子和背包的款式与颜色完全不变
```

视角文本：正面 = 面向镜头正面站立；侧面 = 身体转向画面右侧，标准90度侧面站立；背面 = 背对镜头站立，完整展示背部和背包。

关键帧侧（图1 = 设定图，图2 = 地标）前缀：

```
图1是出镜人物的三视图设定图（从左到右依次是正面、侧面、背面，是同一个人），图2是「{地标}」的实景参考图。把图1中的这一个人物放进图2的实景中，画面里只出现一个人，不要画出设定图的拼图或多个人物，保持人物的脸、发型和服装不变，保持地标的形状与比例、清晰可辨。
```

## 拼图规格

正 | 侧 | 背 横向拼接，等高，无间隙留白以外的装饰，保存为 JPEG（q92）。每张三视图约 768×1376，拼后 2304×1376。

## 未验证与风险

- **没有真人实拍照**：两个素材都是 AI 生成的写实图，真人照会不会漂脸、背景更乱时三视图是否稳定，都没测。
- 脸部一致性只是肉眼看，没有量化；样本只有 2 角色、12 张关键帧、1 个组合的三视图（固定种子）。
- 关键帧只测了侧身构图；正面、背身、近景、半身镜头没测。设定图拼图在 9:16 工作流里的缩放对脸部细节的影响没测。
- 没测直出视频（H3 Ref2VA）用设定图作人物参考的效果。
- 没做方案 B。
- 设定图里三个视角的服装一致性只在这两个角色上确认。
